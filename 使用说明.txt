宣传委员打卡 · 使用说明
========================================

一、平时怎么用
----------------------------------------
双击本文件夹里的「一键打卡」（或「一键打卡.pyw」）→ 打开界面：

  1. 把截图从资源管理器拖进对应的星期格子（也可以点格子里的「＋ 添加」，
     或者截图后直接按 Ctrl+V 粘进当前格）
  2. 看下周次对不对（默认按截图日期自动算，用 ◀ ▶ 改）
  3. 点右下角「生成 Word 打卡表」

生成的 Word 就放在本文件夹里，程序会问你要不要直接打开。


二、文件夹里都是什么
----------------------------------------
  一键打卡.lnk      ← 带图标的快捷方式，平时双击它
  一键打卡.pyw      ← 同上，放哪都能用（快捷方式要是失效了就用这个）
  程序\             ← 代码，平时不用管
  打卡表模板.docx    ← 表格模板，别删、别改名
  聊天记录截图\      ← 按星期几归位的那批截图
  日期截图\          ← 塞进「备用格」的那批截图
  剪贴板截图\        ← Ctrl+V 粘贴时自动存的图（用到才出现）
  打卡安排.json     ← 你上次的归位安排（删了也没事，会重新扫）


三、把整个文件夹搬走 / 复制到别的电脑
----------------------------------------
本文件夹是「自带口粮」的：程序、模板、截图都在里面，整个文件夹
剪切/复制到任何地方（U 盘、别的电脑）都能用，前提是那台电脑装了
Python 3 和 PySide6。

Windows 快捷方式里存的是绝对路径，所以**搬走以后「一键打卡.lnk」可能失效**：
双击「一键打卡.pyw」打开一次，它会自动把快捷方式修到新位置，之后就正常了。
（换句话说：快捷方式打不开时，永远是双击「一键打卡.pyw」。）


四、命令行（一般用不到）
----------------------------------------
  python 程序\打卡表.py --week 6      指定周次生成
  python 程序\打卡表.py --check       只看截图会被怎么归位，不生成


五、出问题怎么办
----------------------------------------
* 界面打不开：先确认 Python 和 PySide6 在不在
      pip install PySide6
* 提示「找不到模板」：确认「打卡表模板.docx」还在本文件夹里、没改名
* 想回到最早的版本：见 程序\旧版备份\打卡表_原版.py
